# Surendra & Surekha Wedding Invitation
Responsive bilingual wedding invitation website.

## Included
- Opening cover with “శ్రీ గణేశాయ నమః” followed by “Yadavalli's wedding invitation”
- Groom profile displayed first, bride second
- Countdown and wedding details
- Three event cards only: Haldi, Wedding, Satyanarayana Vratham
- Reception event card/column removed as requested
- Groom's house tag line removed from every event; no house tag lines are shown
- Venue directions and RSVP placeholder

## Remaining before publication
- Upload groom and bride portraits if you want them displayed.
- Add WhatsApp number to enable RSVP.
- Optionally provide exact map pin and pending event times.
- Deploy to a static hosting provider to obtain a public link.


Music: The floating ♫ button embeds the official UV Creations YouTube upload of “The Soul of Radhe Shyam”. Tap to start; tap again to stop. Playback depends on YouTube availability and the visitor’s connection. The track is streamed from YouTube and is not bundled as an audio file.
